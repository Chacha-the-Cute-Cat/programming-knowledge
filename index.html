从零开始：用 TypeScript 在命令行生成 HTML

这是一份可以跟着敲的手把手教程。你会先理解 TypeScript 的编译流程，再写一个脚本， 从命令行生成一个真实的 index.html 文件，并用浏览器打开。

1. 教程目标

学完后你会掌握：

  • 在命令行初始化一个 TypeScript 项目
  • 理解 tsconfig.json 的关键配置
  • 把 .ts 编译成可执行的 .js
  • 用 Node.js 运行编译产物
  • 让脚本自动写出一个 index.html 文件
重要概念：TypeScript 不能直接由浏览器或 Node.js 运行。它需要先由编译器 tsc 转换成 JavaScript。

2. 环境准备

先确认已经安装 Node.js 和 npm。打开终端，运行：

node -v
npm -v

建议使用 Node.js 18 或更高版本。如果没有安装，请先到官网安装 LTS 版本：

https://nodejs.org/

3. 初始化项目

在你希望存放代码的位置打开终端，依次执行：

mkdir ts-html-demo
cd ts-html-demo
npm init -y

这会生成一个 package.json，它记录项目名称、脚本和依赖。 后面我们会把编译命令也放进去。

4. 安装 TypeScript

npm install -D typescript @types/node

这里的两项依赖分别是：

  • typescript：TypeScript 编译器 tsc
  • @types/node：让 TypeScript 认识 Node.js 的 fs、path 等模块
-D 表示安装到开发依赖。因为编译后的运行环境只需要 JavaScript，不需要 TypeScript 编译器。

5. 配置 tsconfig.json

生成默认配置文件：

npx tsc --init

然后把它替换为下面这份精简配置：

{
  "compilerOptions": {
    "target": "ES2020",
    "module": "CommonJS",
    "rootDir": "src",
    "outDir": "dist",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true
  },
  "include": ["src"]
}

关键字段说明：

  • rootDir: "src"：TypeScript 源码放在 src 目录
  • outDir: "dist"：编译后的 JavaScript 输出到 dist 目录
  • strict: true：开启严格类型检查，适合认真学类型

6. 编写第一段 TypeScript 代码

先创建源码目录：

mkdir src

新建文件 src/generate.ts，写入以下内容：

import { writeFileSync } from "fs";
import { join } from "path";

type Course = {
  name: string;
  hours: number;
};

const courses: Course[] = [
  { name: "TypeScript 基础", hours: 4 },
  { name: "类型与接口", hours: 3 },
  { name: "泛型", hours: 2 },
];

function renderCourse(course: Course): string {
  return `<li>${course.name}（${course.hours} 小时）</li>`;
}

function buildPage(courseList: Course[]): string {
  const items = courseList.map(renderCourse).join("\n      ");

  return `<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>TypeScript 生成的页面</title>
  </head>
  <body>
    <main>
      <h1>TypeScript 命令行生成 HTML</h1>
      <p>这个文件由 TypeScript 编译后的 Node.js 脚本生成。</p>
      <ul>
      ${items}
      </ul>
    </main>
  </body>
</html>`;
}

const outputPath = join(__dirname, "..", "index.html");
writeFileSync(outputPath, buildPage(courses), "utf8");

console.log("已生成:", outputPath);
这段代码用到了类型标注、类型别名、数组类型和模板字符串。它们不会进入最终的 HTML， 只负责在编译阶段帮你检查错误。

7. 编译与运行

先手动编译一次：

npx tsc

编译完成后，会生成 dist/generate.js。 再用 Node.js 执行它： 

node dist/generate.js

你会看到类似输出：

已生成: D:\你的路径\ts-html-demo\index.html

把这两步放进 package.json，以后一条命令完成： 

{
  "scripts": {
    "build": "tsc",
    "generate": "tsc && node dist/generate.js"
  }
}

然后运行：

npm run generate

8. 查看生成的 HTML 文件

项目根目录会多出一个 index.html。Windows 下可以直接打开：

start .\index.html

macOS 下：

open index.html

Linux 下：

xdg-open index.html
如果你想边改边自动编译，可以另开一个终端运行 npx tsc --watch。

9. 在浏览器里直接运行 TypeScript

上一节是“用 TypeScript 生成 HTML 文件”。如果你更想写一个网页，让浏览器加载编译后的 JavaScript， 可以换成下面的做法。

编写 src/index.ts

const app = document.getElementById("app")!;

function greet(name: string): string {
  return `你好，${name}！`;
}

const h1 = document.createElement("h1");
h1.textContent = greet("TypeScript");
app.appendChild(h1);

编写 index.html

<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <title>TypeScript 网页</title>
  </head>
  <body>
    <div id="app"></div>
    <script src="dist/index.js"></script>
  </body>
</html>

编译后直接打开页面：

npx tsc
start .\index.html
如果浏览器报错说找不到 dist/index.js，请先确认你已经执行了 npx tsc，并且 tsconfig.json 里包含 "lib": ["DOM"]。

10. 常用命令速查

# 初始化项目
npm init -y

# 安装编译器
npm install -D typescript @types/node

# 生成默认配置
npx tsc --init

# 编译一次
npx tsc

# 只检查类型，不生成文件
npx tsc --noEmit

# 监视文件变化并自动编译
npx tsc --watch

# 编译并执行生成脚本
npm run generate

11. 下一步学什么

掌握基础后，可以按这个顺序继续：

  • 学习 interface 和 type 的区别
  • 理解联合类型、字面量类型和类型收窄
  • 用泛型写出可复用的函数
  • 了解 tsconfig 里的 strict 系列选项
  • 尝试用 tsx 直接运行 TypeScript 脚本

完整文档可以参考 TypeScript 官方网站： https://www.typescriptlang.org/
