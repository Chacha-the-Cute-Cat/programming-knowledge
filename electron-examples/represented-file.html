设置窗口所代表的文件，并显示未保存状态

在 BrowserWindow 中展示文件 Represented File

第 16 / 20 个原创示例

这个例子做什么

这是自己编写的 macOS 文件表示示例，展示窗口标题栏中的文件图标和编辑状态。

操作步骤

  1. 打开 PowerShell，进入总目录：
    cd D:\hf\L\electron
  2. 创建独立项目目录并进入：
    New-Item -ItemType Directory -Path apps\represented-file -Force
cd apps\represented-file
  3. 初始化 npm 项目：
    npm init -y
  4. 设置主入口和启动脚本：
    npm pkg set main="main.js"
npm pkg set scripts.start="electron ."
  5. 安装 Electron，国内网络可先设置镜像：
    $env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install --save-dev electron
  6. 按照下面“代码文件”一节创建对应文件。文件名必须一致。
  7. 回到 PowerShell 运行：
    npm start

代码文件

main.js

设置 representedFilename 和 documentEdited。

main.js
const { app, BrowserWindow, ipcMain } = require('electron')
const path = require('node:path')

function createWindow () {
  const win = new BrowserWindow({
    width: 720,
    height: 420,
    webPreferences: {
      preload: path.join(__dirname, 'preload.js')
    }
  })
  win.loadFile('index.html')
  return win
}

let mainWindow = null

ipcMain.on('file:open', (event, filePath) => {
  mainWindow.setRepresentedFilename(filePath)
  mainWindow.setDocumentEdited(true)
})

app.whenReady().then(() => {
  mainWindow = createWindow()
})

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') app.quit()
})

preload.js

暴露打开文件方法。

preload.js
const { contextBridge, ipcRenderer } = require('electron')

contextBridge.exposeInMainWorld('file', {
  open: (filePath) => ipcRenderer.send('file:open', filePath)
})

index.html

按钮模拟打开一个文件。

index.html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Represented File 示例</title>
</head>
<body>
  <h1>在窗口中展示文件</h1>
  <button id="open">模拟打开文件</button>
  <script src="renderer.js"></script>
</body>
</html>

renderer.js

调用 preload 暴露的方法。

renderer.js
document.getElementById('open').addEventListener('click', () => {
  window.file.open('/Users/example/Documents/note.txt')
})

运行后应该看到什么

在 macOS 上运行，点击按钮后窗口标题栏会显示文件图标，并出现“已编辑”的圆点标记。

补充说明

这个 API 只在 macOS 上有效，Windows 和 Linux 可以忽略。
