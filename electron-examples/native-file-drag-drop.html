从窗口拖出一个动态生成的文件到系统

原生文件拖 & 放 Native File Drag & Drop

第 9 / 20 个原创示例

这个例子做什么

这是自己编写的拖拽示例：页面元素被拖出窗口时，主进程动态创建文件并调用 webContents.startDrag。

操作步骤

  1. 打开 PowerShell，进入总目录：
    cd D:\hf\L\electron
  2. 创建独立项目目录并进入：
    New-Item -ItemType Directory -Path apps\native-file-drag-drop -Force
cd apps\native-file-drag-drop
  3. 初始化 npm 项目：
    npm init -y
  4. 设置主入口和启动脚本：
    npm pkg set main="main.js"
npm pkg set scripts.start="electron ."
  5. 安装 Electron，国内网络可先设置镜像：
    $env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install --save-dev electron
  6. 按照下面“代码文件”一节创建对应文件。文件名必须一致。
  7. 回到 PowerShell 运行：
    npm start

代码文件

main.js

接收拖拽事件，创建临时文件后调用 startDrag。

main.js
const { app, BrowserWindow, ipcMain } = require('electron')
const path = require('node:path')
const fs = require('node:fs')

function createWindow () {
  const win = new BrowserWindow({
    width: 640,
    height: 420,
    webPreferences: {
      preload: path.join(__dirname, 'preload.js')
    }
  })
  win.loadFile('index.html')
}

ipcMain.on('drag:start', (event, fileName) => {
  const filePath = path.join(app.getPath('temp'), fileName)
  fs.writeFileSync(filePath, '这是从 Electron 窗口拖出来的文件。')
  event.sender.startDrag({ file: filePath })
})

app.whenReady().then(() => {
  createWindow()
  app.on('activate', () => {
    if (BrowserWindow.getAllWindows().length === 0) createWindow()
  })
})

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') app.quit()
})

preload.js

暴露 startDrag 方法。

preload.js
const { contextBridge, ipcRenderer } = require('electron')

contextBridge.exposeInMainWorld('drag', {
  start: (fileName) => ipcRenderer.send('drag:start', fileName)
})

index.html

给一个元素设置 draggable，并加载 renderer.js。

index.html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>原生文件拖放</title>
  <style>
    #drag { display: inline-block; padding: 20px; border: 2px dashed #0284c7; border-radius: 10px; user-select: none; }
  </style>
</head>
<body>
  <h1>把下面的方块拖到桌面或文件夹</h1>
  <div id="drag" draggable="true">拖我出去</div>
  <script src="renderer.js"></script>
</body>
</html>

renderer.js

在 ondragstart 中调用 preload 暴露的方法。

renderer.js
document.getElementById('drag').ondragstart = (event) => {
  event.preventDefault()
  window.drag.start('dragged-from-electron.txt')
}

运行后应该看到什么

运行后把方块拖到桌面或文件夹，会生成一个 dragged-from-electron.txt 文件。

补充说明

startDrag 中的 file 必须指向真实存在的本地文件。
