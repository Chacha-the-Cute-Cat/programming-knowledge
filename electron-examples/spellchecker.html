在内容编辑区域启用拼写检查并提供右键建议

拼写检查器 Spellchecker

第 17 / 20 个原创示例

这个例子做什么

这是自己编写的拼写检查示例，设置系统拼写语言，并给拼写错误单词提供建议菜单。

操作步骤

  1. 打开 PowerShell，进入总目录：
    cd D:\hf\L\electron
  2. 创建独立项目目录并进入：
    New-Item -ItemType Directory -Path apps\spellchecker -Force
cd apps\spellchecker
  3. 初始化 npm 项目：
    npm init -y
  4. 设置主入口和启动脚本：
    npm pkg set main="main.js"
npm pkg set scripts.start="electron ."
  5. 安装 Electron，国内网络可先设置镜像：
    $env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install --save-dev electron
  6. 按照下面“代码文件”一节创建对应文件。文件名必须一致。
  7. 回到 PowerShell 运行：
    npm start

代码文件

main.js

设置拼写语言，并在右键菜单中展示建议。

main.js
const { app, BrowserWindow, Menu, session } = require('electron')

function createWindow () {
  const win = new BrowserWindow({
    width: 760,
    height: 500
  })
  win.loadFile('index.html')

  win.webContents.on('context-menu', (event, params) => {
    const template = []
    if (params.misspelledWord) {
      for (const suggestion of params.dictionarySuggestions) {
        template.push({
          label: suggestion,
          click: () => win.webContents.replaceMisspelling(suggestion)
        })
      }
      template.push({ type: 'separator' })
    }
    template.push(
      { role: 'cut' },
      { role: 'copy' },
      { role: 'paste' }
    )
    Menu.buildFromTemplate(template).popup({ window: win })
  })
}

app.whenReady().then(() => {
  session.defaultSession.setSpellCheckerLanguages(['en-US'])
  createWindow()
  app.on('activate', () => {
    if (BrowserWindow.getAllWindows().length === 0) createWindow()
  })
})

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') app.quit()
})

index.html

使用 contenteditable，方便输入并触发拼写检查。

index.html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>拼写检查器示例</title>
  <style>
    #editor { width: 90%; min-height: 200px; border: 1px solid #cbd5e1; padding: 12px; outline: none; }
  </style>
</head>
<body>
  <h1>拼写检查器</h1>
  <div id="editor" contenteditable="true">This is an exmple of a misspeled word.</div>
</body>
</html>

运行后应该看到什么

运行后在编辑区右键，拼写错误单词下方会有红色波浪线，右键会显示正确拼写建议。

补充说明

建议语言由 setSpellCheckerLanguages 决定。这里使用 en-US，因此英文单词更容易触发。
