设置 JumpList、窗口闪烁和进度条

任务栏自定义 Windows Taskbar

第 19 / 20 个原创示例

这个例子做什么

这是自己编写的 Windows 任务栏示例，演示用户任务、闪烁提示和进度显示。

操作步骤

  1. 打开 PowerShell，进入总目录：
    cd D:\hf\L\electron
  2. 创建独立项目目录并进入：
    New-Item -ItemType Directory -Path apps\windows-taskbar -Force
cd apps\windows-taskbar
  3. 初始化 npm 项目：
    npm init -y
  4. 设置主入口和启动脚本：
    npm pkg set main="main.js"
npm pkg set scripts.start="electron ."
  5. 安装 Electron，国内网络可先设置镜像：
    $env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install --save-dev electron
  6. 按照下面“代码文件”一节创建对应文件。文件名必须一致。
  7. 回到 PowerShell 运行：
    npm start

代码文件

main.js

使用 app.setUserTasks、win.flashFrame 和 win.setProgressBar。

main.js
const { app, BrowserWindow } = require('electron')

function createWindow () {
  const win = new BrowserWindow({
    width: 720,
    height: 420
  })
  win.loadFile('index.html')

  app.setUserTasks([
    {
      program: process.execPath,
      arguments: '--new-window',
      title: '新建窗口',
      description: '打开一个新的应用窗口'
    }
  ])

  win.setProgressBar(0.65)
  win.flashFrame(true)
  setTimeout(() => win.flashFrame(false), 3000)
}

app.whenReady().then(() => {
  createWindow()
  app.on('activate', () => {
    if (BrowserWindow.getAllWindows().length === 0) createWindow()
  })
})

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') app.quit()
})

运行后应该看到什么

运行后观察任务栏按钮：有进度、会闪烁，右键图标会出现“新建窗口”。

补充说明

这些功能主要针对 Windows。JumpList 任务需要应用保持运行或正确注册。
