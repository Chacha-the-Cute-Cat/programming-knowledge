在 Linux .desktop 文件中定义应用快捷动作

桌面启动器快捷操作 Linux Desktop Actions

第 6 / 20 个原创示例

这个例子做什么

这是针对 Linux 桌面环境的原创示例，演示 .desktop 文件的 Actions 配置，并让 Electron 读取传入参数。

操作步骤

  1. 打开 PowerShell，进入总目录：
    cd D:\hf\L\electron
  2. 创建独立项目目录并进入：
    New-Item -ItemType Directory -Path apps\linux-desktop-actions -Force
cd apps\linux-desktop-actions
  3. 初始化 npm 项目：
    npm init -y
  4. 设置主入口和启动脚本：
    npm pkg set main="main.js"
npm pkg set scripts.start="electron ."
  5. 安装 Electron，国内网络可先设置镜像：
    $env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install --save-dev electron
  6. 按照下面“代码文件”一节创建对应文件。文件名必须一致。
  7. 回到 PowerShell 运行：
    npm start

代码文件

my-app.desktop

把 Exec 路径替换成你的应用实际路径。

my-app.desktop
[Desktop Entry]
Type=Application
Name=My Electron App
Comment=Electron 桌面快捷操作示例
Exec=/opt/my-app/my-app %U
Actions=new;open

[Desktop Action new]
Name=新建窗口
Exec=/opt/my-app/my-app --new

[Desktop Action open]
Name=打开文件
Exec=/opt/my-app/my-app --open

main.js

读取命令行参数，打印用户选择的桌面动作。

main.js
const { app, BrowserWindow } = require('electron')

function createWindow () {
  const win = new BrowserWindow({ width: 700, height: 420 })
  win.loadFile('index.html')
}

app.whenReady().then(() => {
  const action = process.argv.find((item) => item === '--new' || item === '--open')
  if (action) console.log('桌面动作：' + action)
  createWindow()
})

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') app.quit()
})

index.html

页面提示这是 Linux 桌面动作示例。

index.html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Linux Desktop Actions</title>
</head>
<body>
  <h1>Linux 桌面快捷操作</h1>
  <p>请查看终端，确认收到的 --new 或 --open 参数。</p>
</body>
</html>

运行后应该看到什么

在 Linux 上安装 .desktop 文件后，右键应用图标会看到“新建窗口”和“打开文件”两个动作。

补充说明

这个功能主要针对 Linux。Windows 可以使用 app.setUserTasks 实现类似的 JumpList。
