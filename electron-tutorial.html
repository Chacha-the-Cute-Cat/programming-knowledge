先搞清楚：Electron 是什么

Electron 是 GitHub 开源的一个桌面应用开发框架。它把 Chromium 浏览器内核和 Node.js 运行时组合在一起，让你可以用 HTML、CSS、JavaScript 编写 Windows、macOS、Linux 桌面软件。VS Code、Slack、Discord 等很多软件都用它开发。

一个 Electron 应用通常由两个重要部分组成：

  • 主进程（Main Process）：运行 Node.js，负责创建窗口、调用系统能力，例如对话框、菜单、文件系统。
  • 渲染进程（Renderer Process）：负责展示 HTML 界面，和普通网页类似，但安全限制更严格。

为了安全地在两者之间通信，我们还会使用 预加载脚本（Preload）。后面的教程会逐步带你走完这个结构。

3安装 Electron

Electron 通常作为项目的开发依赖安装，这样每个项目可以锁定自己的 Electron 版本。执行下面的命令：

npm install --save-dev electron

这个命令会下载 Electron 的二进制文件，可能需要几分钟。安装完成后，可以确认版本：

npx electron --version
npm ls electron
如果下载很慢：可以临时使用国内镜像，再重新安装。镜像变量只对当前 PowerShell 窗口有效。 
$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"

5编写主进程 main.js

把下面的内容完整粘贴到 main.js。它负责创建应用窗口，并注册两个 IPC 处理程序：读取版本信息、打开文件选择框。

const { app, BrowserWindow, ipcMain, dialog } = require('electron');
const path = require('node:path');

function createWindow() {
  const win = new BrowserWindow({
    width: 960,
    height: 680,
    title: '我的第一个 Electron 应用',
    webPreferences: {
      preload: path.join(__dirname, 'preload.js'),
      contextIsolation: true,
      nodeIntegration: false
    }
  });

  win.loadFile('index.html');

  // 开发阶段自动打开 DevTools，方便调试
  win.webContents.openDevTools({ mode: 'detach' });
}

app.whenReady().then(() => {
  createWindow();

  app.on('activate', () => {
    if (BrowserWindow.getAllWindows().length === 0) {
      createWindow();
    }
  });
});

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') {
    app.quit();
  }
});

// 渲染进程调用：获取版本信息
ipcMain.handle('app:get-versions', () => {
  return {
    electron: process.versions.electron,
    chrome: process.versions.chrome,
    node: process.versions.node
  };
});

// 渲染进程调用：打开文件选择框
ipcMain.handle('dialog:open-file', async () => {
  const result = await dialog.showOpenDialog({
    title: '请选择一个文件',
    properties: ['openFile']
  });

  if (result.canceled) {
    return null;
  }

  return result.filePaths[0];
});

6编写预加载脚本 preload.js

把下面的内容粘贴到 preload.js。它的作用是在安全的边界上，把主进程能力封装成渲染进程可以调用的 API。

const { contextBridge, ipcRenderer } = require('electron');

contextBridge.exposeInMainWorld('electronAPI', {
  getVersions: () => ipcRenderer.invoke('app:get-versions'),
  chooseFile: () => ipcRenderer.invoke('dialog:open-file')
});

这里我们故意没有把 ipcRenderer 直接暴露给网页，而是只暴露两个明确的方法。这是 Electron 官方推荐的安全写法。

8编写渲染进程 renderer.js

把下面的内容粘贴到 renderer.js。它调用预加载脚本暴露出来的 API，把结果展示到页面上。

const versionsEl = document.getElementById('versions');
const chooseFileBtn = document.getElementById('chooseFile');
const resultEl = document.getElementById('result');

async function loadVersions() {
  const versions = await window.electronAPI.getVersions();
  versionsEl.textContent =
    'Electron ' + versions.electron +
    ' / Chromium ' + versions.chrome +
    ' / Node ' + versions.node;
}

chooseFileBtn.addEventListener('click', async () => {
  const filePath = await window.electronAPI.chooseFile();
  resultEl.textContent = filePath ? '你选择了：' + filePath : '没有选择文件';
});

loadVersions();

9配置 package.json

打开 package.json，确认 main 指向 main.js，并在 scripts 中增加启动命令。关键部分如下：

{
  "name": "hello-electron",
  "version": "1.0.0",
  "description": "我的第一个 Electron 应用",
  "main": "main.js",
  "scripts": {
    "start": "electron ."
  },
  "devDependencies": {
    "electron": "^44.0.0"
  }
}

注意：electron 的版本号以你实际安装的版本为准，不需要手动改成完全一样。只要 "start": "electron ." 存在即可。

10运行你的第一个应用

回到 PowerShell，执行：

npm start

如果一切正常，你会看到：

  • 一个桌面窗口弹出，标题是“我的第一个 Electron 应用”。
  • 页面显示 Electron、Chromium、Node 的版本号。
  • DevTools 调试窗口自动打开。
  • 点击“选择文件”按钮，会弹出系统文件选择框。
恭喜！到这里，你已经完成了从 0 到 1 的第一个 Electron 应用。

11调试技巧

渲染进程调试

  • 打开/关闭 DevTools：在窗口中按 Ctrl + Shift + I。
  • 刷新页面：按 Ctrl + R。
  • 在 renderer.js 中使用 console.log()，日志会出现在 DevTools 的 Console 面板。

主进程调试

在 main.js 中使用 console.log()，日志会直接输出到你运行 npm start 的那个 PowerShell 终端里。

常见检查顺序

  1. 先看 PowerShell 终端有没有报错。
  2. 再看 DevTools Console 有没有报错。
  3. 确认 main.js 中文件名大小写正确，例如 index.html。
  4. 修改主进程代码后，需要完全退出应用，再重新执行 npm start。

12理解 IPC 与安全边界

你刚刚已经完成了一次完整的 IPC 通信，流程是：

renderer.js
  └─ window.electronAPI.getVersions()
        └─ ipcRenderer.invoke('app:get-versions')
              └─ ipcMain.handle('app:get-versions')
                    └─ 返回版本对象

关于安全，记住三条原则：

  • 保持 contextIsolation: true，不要在真实项目里为了省事关闭它。
  • 保持 nodeIntegration: false，渲染进程不要直接访问 Node.js。
  • 通过 contextBridge.exposeInMainWorld() 暴露最小化 API，而不是暴露整个 ipcRenderer。

13常见问题排查

1. 提示 electron 不是内部或外部命令

不要直接运行 electron .。项目里安装的 Electron 没有加入系统 PATH，请使用：

npm start

也可以使用 npx electron .。

2. npm 安装 Electron 很慢或失败

设置镜像后重新安装：

$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm install --save-dev electron

3. PowerShell 提示禁止运行脚本

这通常不是 Electron 本身的问题，而是 PowerShell 执行策略限制。你可以只对当前用户放宽：

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

4. 窗口没有出现，但终端没有明显报错

  • 检查 win.loadFile('index.html') 的文件名是否正确。
  • 检查四个文件是否都在项目根目录。
  • 在主进程的 createWindow() 里加 console.log('window created')，观察终端输出。

5. 页面提示 window.electronAPI is undefined

通常说明 preload.js 没有被正确加载。请确认 main.js 里的 preload 路径是 path.join(__dirname, 'preload.js')，并且文件名完全一致。

14打包成安装程序

学习阶段先把应用跑起来已经足够。如果你想把它打包成一个 Windows 安装包，可以使用 electron-builder。

先安装打包工具：

npm install --save-dev electron-builder

然后更新 package.json，增加打包脚本和配置：

{
  "name": "hello-electron",
  "version": "1.0.0",
  "description": "我的第一个 Electron 应用",
  "main": "main.js",
  "scripts": {
    "start": "electron .",
    "dist": "electron-builder"
  },
  "devDependencies": {
    "electron": "^44.0.0",
    "electron-builder": "^26.0.12"
  },
  "build": {
    "appId": "com.example.hello-electron",
    "productName": "Hello Electron",
    "win": {
      "target": "nsis"
    }
  }
}

执行打包：

npm run dist

打包完成后，安装程序通常位于项目的 dist 目录中，是一个 .exe 文件。
