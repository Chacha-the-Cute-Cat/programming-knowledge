1. TypeScript 是什么

TypeScript 是 JavaScript 的超集，由微软开发。它在 JavaScript 的基础上增加了静态类型系统， 最后仍然会编译成普通的 JavaScript 运行。

也就是说，你写的 .ts 文件不能直接运行，需要先经过编译器 tsc 转换成 .js 文件。

TypeScript 的类型只在编译阶段存在，不会进入最终的 JavaScript。类型系统的作用，是在你写代码时提前发现错误。

2. 为什么使用 TypeScript

下面这段 JavaScript 在运行时才会暴露问题：

const user = { name: "Ada" };
console.log(user.age.toFixed(2));

如果 age 不存在，浏览器会报错。TypeScript 则能在编译阶段告诉你： 

Property 'age' does not exist on type '{ name: string; }'.

它能带来的好处包括：

  • 提前发现拼写错误和类型错误
  • 更好的编辑器和 IDE 自动补全
  • 让函数签名更清晰，减少沟通成本
  • 在大型项目中更容易重构和维护

3. 安装环境

先检查 Node.js 和 npm：

node -v
npm -v

建议使用 Node.js 18 或更高版本。如果未安装，请前往：

https://nodejs.org/

创建项目并安装 TypeScript：

mkdir ts-zero-to-one
cd ts-zero-to-one
npm init -y
npm install -D typescript @types/node

4. 第一个 TypeScript 程序

创建文件 src/hello.ts：

const message: string = "Hello, TypeScript!";
console.log(message);

先用一条简单命令编译它：

npx tsc src/hello.ts --outDir dist --target ES2020 --module commonjs

再用 Node.js 运行编译产物：

node dist/hello.js

你会看到：

Hello, TypeScript!
这里的 : string 就是类型标注。它告诉编译器 message 只能是字符串。

5. 基础类型

TypeScript 内置了这些常用类型：

let isDone: boolean = false;
let age: number = 18;
let username: string = "Ada";

let list: number[] = [1, 2, 3];
let tuple: [string, number] = ["Ada", 28];

let notSure: unknown = 4;
let anything: any = "hello";

function logMessage(): void {
  console.log("没有返回值");
}

几个容易混淆的类型：

  • unknown：不知道具体类型，使用前必须先收窄类型，比较安全
  • any：放弃类型检查，应该尽量少用
  • void：函数没有返回值
  • never：永远不会有返回值，例如抛出异常或死循环

6. 类型推断

大多数时候不需要手动写类型。TypeScript 会根据初始值自动推断： 

let count = 10;        // 推断为 number
let title = "教程";     // 推断为 string
const items = [1, 2, 3]; // 推断为 number[]

当没有初始值，或者类型不明确时，才需要显式标注：

let result: number;
result = 42;
先让 TypeScript 自动推断，必要时再补类型。不要为了写类型而写类型。

7. 函数与类型

参数和返回值都可以标注类型：

function add(a: number, b: number): number {
  return a + b;
}

const greet = (name: string): string => {
  return `Hello, ${name}`;
};

可选参数使用 ?：

function introduce(name: string, age?: number): string {
  return age ? `${name}, ${age} 岁` : name;
}

默认参数也可以写：

function multiply(a: number, b = 2): number {
  return a * b;
}

8. interface 与 type

interface 用来描述对象的形状：

interface User {
  id: number;
  name: string;
  email?: string;
}

const user: User = {
  id: 1,
  name: "Ada",
};

type 可以给任何类型起别名：

type ID = string | number;
type Point = {
  x: number;
  y: number;
};

二者的区别：

  • interface 更适合描述对象，可以被继承和合并声明
  • type 更灵活，能表达联合类型、元组等
  • 日常开发中，描述对象结构优先用 interface，其他复杂类型用 type

9. 联合类型与交叉类型

联合类型表示“可能是 A 或 B”：

type Status = "success" | "error" | "loading";

function render(status: Status): string {
  return `当前状态：${status}`;
}

交叉类型表示“同时拥有 A 和 B 的属性”：

type Named = { name: string };
type Aged = { age: number };

type Person = Named & Aged;

const person: Person = {
  name: "Ada",
  age: 28,
};

10. 类型收窄

当参数是联合类型时，TypeScript 会根据判断自动缩小类型范围：

function format(value: string | number): string {
  if (typeof value === "string") {
    return value.toUpperCase();
  }

  return value.toFixed(2);
}

处理 unknown 时也必须先收窄：

function getLength(value: unknown): number {
  if (typeof value === "string") {
    return value.length;
  }

  return 0;
}
TypeScript 无法确定 unknown 的原始类型，所以不会让你直接访问它的属性。这是它与 any 的重要区别。

11. 泛型

泛型让函数或类型可以处理任意类型，同时保留类型信息：

function first<T>(items: T[]): T | undefined {
  return items[0];
}

const number = first([1, 2, 3]);       // number | undefined
const name = first(["Ada", "Grace"]);  // string | undefined

也可以用泛型约束：

function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const value = getProperty({ id: 1, name: "Ada" }, "name");

这里的 <T> 是类型参数，keyof T 表示 T 的所有键。

12. 类与访问修饰符

TypeScript 的类支持 public、private、protected 和 readonly：

class Animal {
  constructor(protected name: string) {}

  speak(): string {
    return `${this.name} makes a sound.`;
  }
}

class Dog extends Animal {
  speak(): string {
    return `${this.name} barks.`;
  }
}

const dog = new Dog("Lucky");
console.log(dog.speak());

说明：

  • public：任何地方都可以访问
  • private：只有当前类可以访问
  • protected：当前类和子类可以访问
  • readonly：只读，初始化后不能修改

13. 模块导入导出

创建 src/math.ts：

export function add(a: number, b: number): number {
  return a + b;
}

export const PI = 3.14159;

在 src/index.ts 中导入：

import { add, PI } from "./math";

console.log(add(2, 3));
console.log(PI);

也可以使用默认导出：

export default function greet(name: string): string {
  return `Hello, ${name}`;
}

14. tsconfig 配置

生成默认配置文件：

npx tsc --init

替换成下面这份适合入门的配置：

{
  "compilerOptions": {
    "target": "ES2020",
    "module": "CommonJS",
    "rootDir": "src",
    "outDir": "dist",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true
  },
  "include": ["src"]
}

关键配置说明：

  • target：编译成哪个版本的 JavaScript
  • module：使用哪种模块系统
  • rootDir：源码根目录
  • outDir：输出目录
  • strict：开启所有严格类型检查

15. 编译与运行

在 package.json 中添加脚本：

{
  "scripts": {
    "build": "tsc",
    "start": "node dist/index.js"
  }
}

编译：

npm run build

运行：

npm run start

开发时也可以让编译器监听文件变化：

npx tsc --watch

只想检查类型而不生成文件：

npx tsc --noEmit

16. 常用实用类型

TypeScript 提供了一批内置工具类型，可以组合出更简洁的代码：

type Todo = {
  title: string;
  completed: boolean;
};

type TodoPatch = Partial<Todo>;
type TodoTitle = Pick<Todo, "title">;
type TodoWithoutCompleted = Omit<Todo, "completed">;
type ReadonlyTodo = Readonly<Todo>;

常用工具类型：

  • Partial<T>：所有属性变成可选
  • Required<T>：所有属性变成必填
  • Pick<T, K>：只保留指定属性
  • Omit<T, K>：移除指定属性
  • Readonly<T>：所有属性变成只读
  • Record<K, T>：构造一个键值对象类型

17. 下一步学什么

掌握这些基础后，可以按顺序继续：

  • 练习 keyof、typeof 和条件类型
  • 学习声明合并和命名空间
  • 用 tsx 直接运行 TypeScript 脚本
  • 尝试在 React、Vue 或 Node.js 项目中使用 TypeScript
  • 阅读官方文档和 utility-types 工具类型
