Phase 13 — Context Architecture

1. 功能

Context 决定模型看到什么，包括 system/developer prompt、conversation、tool result、memory、files、workspace、skills、AGENTS.md。

2. LobsterAI 侧

[源码已确认] 相关模块：

  • src/shared/cowork/：会话、消息、上下文使用
  • src/main/libs/agentEngine/openclawRuntimeAdapter.ts：context usage / compaction 转发
  • src/main/libs/agentEngine/openclawApprovalBridge.ts
  • src/main/libs/openclawConfigSync.ts：workspace AGENTS.md、skills、system prompt
  • src/main/skills/skillManager.ts：路由 prompt

[源码已确认] Adapter 方法：

  • getContextUsage()：coworkEngineRouter.ts
  • compactContext()：coworkEngineRouter.ts

3. OpenClaw 侧

[源码已确认] 存在独立 context-engine：

  • openclaw/src/context-engine/
  • init.ts
  • types.ts
  • registry.ts
  • compaction-watchdog.ts
  • runtime-settings.ts

[源码已确认] 记忆：

  • openclaw/src/memory/
  • openclaw/src/memory-host-sdk/

4. Context 组成

[推测，待进一步验证] 组成包含：

  • system/agent prompt
  • conversation history
  • tool call / tool result
  • memory facts
  • workspace AGENTS.md
  • skill 路由 prompt
  • selected text / attachments / fork context

5. Compaction

[源码已确认] OpenClaw 有 compaction 相关：

  • agent-compaction-constants.ts
  • agent-hooks/compaction-safeguard.ts
  • agent-hooks/compaction-instructions.ts
  • context-engine/compaction-watchdog.ts

[源码已确认] LobsterAI adapter 转发 contextMaintenance、contextUsageUpdate 事件。

6. 学习重点

  • Context 由 OpenClaw 构建，LobsterAI 提供配置、workspace 文件和 UI 反馈。
  • Compaction 有质量保障、watchdog 和 instruction，是 Agent 长任务的关键设计。
