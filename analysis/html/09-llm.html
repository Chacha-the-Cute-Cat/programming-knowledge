Phase 10 — LLM Architecture

1. 功能

LLM 调用主要在 OpenClaw runtime 中发生；LobsterAI 负责 provider/model 配置、token proxy、模型迁移和 UI 展示。

5. 推测与待验证

[推测，待 Phase 4 深挖] 实际 chat/completion、SSE/streaming、retry、timeout、token usage 的实现细节需要继续追踪 OpenClaw src/llm 与 src/agents/embedded-agent-runner。

6. 学习重点

  • Provider/model 抽象在 OpenClaw，LobsterAI 主要做账号/配置/代理接入。
  • lobsterai-server 是后端代理模型，OpenClaw 通过 token proxy 和 compatibility patch 接入。
