4. 错误处理策略

[推测，待进一步验证] 主要策略：

  • transient network -> 重连
  • LLM/provider 错误 -> retry/fallback
  • tool 错误 -> tool result 反馈给模型
  • gateway timeout -> 降级或重试
  • 用户 stop -> 跨层 abort

5. 学习重点

  • Gateway client 自带 watchdog 和重连；LobsterAI 在 adapter 之上还有超时降级。
  • 取消不能只靠 HTTP abort，进程和 run 需要独立 abort 通道。
