Phase 07 — WebSocket

1. 功能

LobsterAI 存在多类 WebSocket 连接：OpenClaw Gateway、ASR、IM 平台、Browser CDP。

2. OpenClaw Gateway WebSocket

[源码已确认] 连接信息来自：

  • OpenClawEngineManager.getGatewayConnectionInfo()
  • URL：ws://127.0.0.1:<port>

证据：src/main/libs/openclawEngineManager.ts:620-630。

[源码已确认] 客户端由 OpenClawRuntimeAdapter 管理：

  • gatewayClient：openclawRuntimeAdapter.ts:2544
  • ensureGatewayClientReady()：:6084
  • createGatewayClient()：:6137
  • reconnectGateway()：:4296
  • disconnectGatewayClient()：:4316

[源码已确认] 连接参数：

new GatewayClient({
  url, token, clientDisplayName: 'LobsterAI',
  clientVersion, mode: 'backend', role: 'operator',
  scopes: ['operator.admin'], deviceIdentity: null,
})

证据：openclawRuntimeAdapter.ts:6164-6176。

3. 重连与关闭

[源码已确认] Adapter 字段：

  • gatewayReconnectTimer：:2601
  • gatewayReconnectAttempt：:2602
  • gatewayStoppingIntentionally：:2604
  • WebSocketCloseCode：:255

[源码已确认] onClose 处理：openclawRuntimeAdapter.ts:6224。

4. ASR WebSocket

[源码已确认] src/main/ipcHandlers/asr/handlers.ts：

  • getSafeWebSocketEndpoint
  • realtime session 返回 wsUrl

5. IM 平台 WebSocket

[源码已确认] src/main/im/imGatewayManager.ts：

  • 平台 gateway 启动时同步 OpenClaw config
  • Telegram 等平台通过 gateway WebSocket 接收事件
  • transport: 'imap' | 'ws'：src/main/im/types.ts:522

6. Browser CDP WebSocket

[源码已确认] Browser/CDP 相关：

  • src/shared/browserWebAccess/constants.ts
  • src/main/libs/agentBrowserHost.ts
  • scripts/patches/v2026.8.1/openclaw-browser-cdp-dispatch-rejection.patch

7. 时序图

sequenceDiagram
  participant A as OpenClawRuntimeAdapter
  participant C as GatewayClient
  participant G as OpenClaw Gateway
  A->>G: start gateway process
  A->>C: new GatewayClient(url, token, role, scopes)
  C->>G: WebSocket connect + handshake/auth
  G-->>C: hello/ok
  C-->>A: onHelloOk
  A->>C: request(method, params)
  C->>G: req frame
  G-->>C: res frame / event

8. 学习重点

  • LobsterAI 是 OpenClaw Gateway 的 operator 客户端。
  • 真实 frame 协议需要阅读 packages/gateway-client 和 packages/gateway-protocol。
