Phase 03 — Electron Main

1. 功能

Electron Main 是桌面应用的编排层：生命周期、窗口、IPC、SQLite、OpenClaw、IM、MCP、定时任务、更新、技能、浏览器自动化。

6. 错误处理

[源码已确认] Main 日志使用 electron-log；启动中的非致命错误用 console.warn/console.error 并继续，例如：

  • token proxy 启动失败：main.ts:14784
  • OpenClaw startup config sync 失败：main.ts:14962
  • skill bootstrap 失败按技能记录

7. 安全分析

  • Main 拥有全部系统能力，是最高信任区。
  • IPC handler 输入需校验；通道定义集中在 src/shared/*/constants.ts。
  • Preload 暴露窄 API，不直接暴露 Node 能力。
  • 凭据、token、代理、企业配置等敏感操作集中在 Main，Renderer 不直接读取原始 secret。

8. 如果让我重新设计

将 584 KB 的 main.ts 拆分为：

  • app-lifecycle
  • ipc-registry
  • service-bootstrap
  • openclaw-integration
  • feature-routing

减少单文件巨型状态，同时保留当前的单例 lazy getter 模式。
