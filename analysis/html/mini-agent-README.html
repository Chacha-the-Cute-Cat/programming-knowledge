Mini Agent Desktop

一个不依赖 LobsterAI 核心、独立运行的微型 Agent Loop 实验，复用其“UI -> Agent Loop -> LLM -> Tool -> Shell -> Result”思想。

运行

node src/agent.mjs

默认使用 mock LLM，不需要 API key。mock LLM 第一次返回 run_shell 工具调用，第二次返回最终答案。

结构

  • src/agent.mjs：agent loop、session、turn
  • src/tools.mjs：tool registry、shell tool
  • src/mock-llm.mjs：可替换的 mock LLM
