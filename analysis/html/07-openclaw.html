Phase 08 — OpenClaw Integration

1. 功能

OpenClaw 是 LobsterAI 的 Agent Runtime / Gateway。LobsterAI 负责桌面、会话、IPC、配置、审批、IM、MCP 管理，OpenClaw 负责 Agent Loop、LLM、Tool、Session/Context 的底层执行。

2. 连接点

连接点文件
Gateway 进程管理src/main/libs/openclawEngineManager.ts
配置同步src/main/libs/openclawConfigSync.ts
运行时适配src/main/libs/agentEngine/openclawRuntimeAdapter.ts
Cowork 路由src/main/libs/agentEngine/coworkEngineRouter.ts
审批桥src/main/libs/agentEngine/openclawApprovalBridge.ts
审批控制src/main/libs/agentEngine/openclawApprovalController.ts
Question 控制src/main/libs/agentEngine/openclawQuestionController.ts
版本固定package.json:openclaw.version = v2026.8.1

3. 能力边界

[源码已确认] CoworkAgentEngine = 'openclaw'：src/main/libs/agentEngine/types.ts:19。

coworkEngineRouter.ts:31-36。

LobsterAI 负责

  • Electron 生命周期和窗口
  • SQLite/Cowork 持久化
  • IPC 与 Renderer
  • MCP 配置和启用状态
  • IM 配置和会话映射
  • Skill 安装与安全扫描
  • 定时任务 UI 和本地元数据
  • 审批 UI 与审批桥
  • OpenClaw 进程生命周期和配置

OpenClaw 负责

  • Gateway 进程
  • WebSocket server
  • Session / Turn / Message
  • Agent Loop
  • LLM Provider 调用
  • Tool / MCP 执行
  • Shell / Browser 等工具

6. 学习重点

  • 桌面应用与 Agent Runtime 通过“独立 gateway 进程 + loopback WebSocket”解耦。
  • LobsterAI 不直接实现 Agent Loop，而是通过 adapter 翻译 gateway 事件。
  • 配置同步是热更新/重启策略的关键触发点。
