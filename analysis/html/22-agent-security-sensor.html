Phase 24 — Agent Security Sensor

1. 目标

为 Agent 行为链设计 Sensor 插入点：

Intent -> Context -> LLM Decision -> Tool Call -> Tool Execution -> Process -> File/Network

2. 候选插入点

Sensor候选源码位置可见性精确性建议层级
Intent SensorCoworkService.startSession/continueSession + Main IPC高高Renderer/Main
Context SensorOpenClawRuntimeAdapter.startSession/continueSession、contextMaintenance中高Agent Runtime
LLM SensorOpenClaw src/llm、inference stream高高Agent Runtime
Tool SensoropenclawApprovalBridge、agent-tools.before-tool-call高高Agent Runtime/Tool
Execution SensorOpenClaw embedded runner / gateway turn中高Agent Runtime
Process SensorOpenClawEngineManager、bash-process-registry、OS ETW中高Node/OS
File SensorMain file IPC、OS filesystem minifilter / audit中高OS
Network Sensorgateway WS、token proxy、IM/browser、OS network中中Node/OS

3. 每个 Sensor 的数据格式

[架构建议]

统一使用：

{
  "sensor": "tool|process|file|network",
  "traceId": "agent trace id",
  "agentId": "agent id",
  "sessionId": "session id",
  "turnId": "turn id",
  "ts": "epoch ms",
  "decision": {},
  "resource": {}
}

4. 拿得到 / 拿不到

[源码已确认] LobsterAI 层能拿到 session、message、permission、adapter 事件、MCP 配置、gateway 连接信息。

[推测，待验证] OS 层能拿到 process/file/network 系统事件，但需要额外 Agent 或 ETW/minifilter 支持。

5. 学习重点

  • 单一层无法覆盖完整 Agent trace，需要 User-space、Electron、Agent Runtime、Node、OS 多层 Sensor。
  • TraceId 是关联多层事件的核心，先设计 identity chain。
