Phase 20 — Startup Optimization

1. 功能

分析冷启动到首屏、OpenClaw ready、可交互的性能。

2. 已知启动顺序

[源码已确认] initApp() 顺序见 analysis/01-startup.md。

关键设计：

  • createWindow() 在 skill bootstrap 之前执行：main.ts:14981-14997
  • OpenClaw 启动是异步 fire-and-forget：main.ts:14965
  • skill bootstrap 非阻塞：main.ts:14999

3. 启动 Profiler

[源码已确认] src/main/startupProfiler.ts。

[源码已确认] initApp 使用 StartupProfiler：

  • profiler.mark('app.whenReady')
  • profiler.mark('initStore')
  • profiler.mark('openClawTokenProxy')
  • profiler.mark('enterpriseConfigSync')
  • profiler.mark('applyProxyPreference')

  • profiler.mark('startupCacheWarmup')
  • profiler.mark('prepareOpenClawRuntime')
  • profiler.mark('syncOpenClawConfig')
  • profiler.mark('createWindow')
  • profiler.mark('skillManager')

4. 阻塞点

[源码已确认] await app.whenReady()、await initStore()、await syncOpenClawConfig() 是同步串行路径。

[源码已确认] OpenClaw gateway 启动在 ensureOpenClawRunningForCowork() 中异步执行，不阻塞窗口。

5. 优化建议

[架构建议]

  • 将可并行的 enterprise sync、cache warmup、model migration 按依赖分组并行。
  • syncOpenClawConfig 的首屏依赖部分与完整部分分离。
  • skill bootstrap 保持 lazy，继续延后到首屏之后。
