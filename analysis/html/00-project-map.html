1. 结论摘要

[源码已确认] LobsterAI 不是一个包含 apps/、packages/、turbo.json 的典型 monorepo，而是一个单包 Electron + React 桌面应用：

lobsterai@2026.9.22
├─ Electron Main      src/main/
├─ Electron Preload   src/main/*Preload.ts
├─ React Renderer     src/renderer/
├─ Shared Contracts   src/shared/
├─ Common Runtime     src/common/
├─ Scheduled Tasks    src/scheduledTask/
├─ OpenClaw Runtime   vendor/openclaw-runtime/ + ../openclaw
├─ Skills             SKILLs/ + src/main/skills/
└─ Build/Packaging    scripts/ + vite.config.ts + electron-builder.json

[源码已确认] package.json 是项目控制面：

  • main: dist-electron/main.js
  • engines.node: >=24.15.0 <25
  • engines.npm: >=11.17.0 <12
  • scripts.electron:dev
  • scripts.electron:dev:openclaw
  • scripts.compile:electron
  • scripts.openclaw:runtime:*

[源码已确认] 当前确实存在 package-lock.json，npm 是当前仓库的权威包管理器。根目录下的 pnpm-lock.yaml 和 pnpm-workspace.yaml 是当前工作区中的未跟踪文件，不是仓库基线内容。

[源码已确认] OpenClaw 是当前唯一 agent runtime。CoworkEngineRouter 只接收一个 openclawRuntime，CoworkAgentEngine 的运行时路由也以 OpenClaw 为唯一实现。

[源码已确认] 桌面端运行时边界大致是：

React Renderer
    ↓ window.electron.*
Preload / contextBridge
    ↓ ipcRenderer.invoke / send / on
Electron Main
    ↓ CoworkEngineRouter
OpenClawRuntimeAdapter
    ↓ GatewayClient
OpenClaw Gateway
    ↓ Agent Loop / Tools / MCP
OS / Browser / Shell / External Services

7. Preload 与安全边界

[源码已确认] src/main/preload.ts:140 使用：

contextBridge.exposeInMainWorld('electron', { ... })

暴露的 API 包括但不限于：

  • store：store:get、store:set、store:remove
  • skills
  • mcp
  • kits
  • skin
  • permissions
  • enterprise
  • api：ipcRenderer.invoke('api:fetch')
  • api.stream / cancelStream
  • ipcRenderer.send/on
  • 窗口控制：minimize/toggleMaximize/close

[源码已确认] src/main/main.ts:13885-13899 的 BrowserWindow webPreferences：

nodeIntegration: false
contextIsolation: true
sandbox: true
webSecurity: true
preload: PRELOAD_PATH
webviewTag: true

安全含义：

  • Renderer 不能直接访问 Node.js 的 fs、child_process、process。
  • Renderer 只能通过 preload 暴露的窄 API 进入 Main。
  • 主窗口启用了 sandbox，但 webviewTag: true，因此 webview 相关边界需要单独审计。
  • 凭据相关 preload 是独立隔离面：agentBrowserCredentialPreload.ts、manualCredentialCapturePreload.ts。
