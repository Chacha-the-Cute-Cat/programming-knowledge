3. 开发启动链

[源码已确认] npm run electron:dev：

rimraf dist-electron
  -> npm run compile:electron
  -> concurrently --kill-others
       [0] vite --port 5175 --strictPort
       [1] wait-on 5175 + dist-electron 产物 && electron .

[源码已确认] npm run electron:dev:openclaw：

7. 时序图

sequenceDiagram

  participant VITE as Vite :5175
  participant ELECTRON as Electron Main

  participant RENDERER as React Renderer

  NPM->>VITE: start dev server
  NPM->>ELECTRON: compile + electron .

  MAIN->>MAIN: init store/protocol/library
  MAIN->>MAIN: token proxy + enterprise sync
  MAIN->>OPENCLAW: sync config + ensure gateway running
  MAIN->>RENDERER: createWindow + loadURL(5175)
  RENDERER->>RENDERER: ReactDOM.createRoot(App)
  MAIN->>MAIN: skill bootstrap (non-blocking)

8. 学习重点

  • electron:dev 中 concurrently 的竞态由 wait-on 解决。
  • 主进程先做数据/服务初始化，再显示窗口，窗口显示与 skill bootstrap 解耦。
  • OpenClaw 启动是异步的，避免阻塞首屏。

9. 如果让我重新设计

可以把 initStore、enterpriseConfigSync、syncOpenClawConfig 中可并行的步骤用受控的 Promise 组并发；首屏只依赖 store 和窗口创建，其余服务用 readiness 门控。
