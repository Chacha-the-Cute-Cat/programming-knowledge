Phase 04 — Renderer / React

1. 功能

Renderer 是 LobsterAI 的用户界面，负责聊天、session、artifact、library、scheduled task、IM、MCP、skill、设置、权限弹窗等。

6. UI 事件与 IPC

Renderer 不直接访问 Node.js，所有系统能力通过 window.electron.* 间接访问。

7. 安全分析

  • contextIsolation 隔离 DOM 与 preload。
  • Redux store 中的敏感状态不应包含原始 API key。
  • 消息/权限数据经过 IPC 边界，需注意大数据传输和内容大小限制。

8. 如果让我重新设计

把 App.tsx 的 91 KB 顶层逻辑拆为：

  • view router
  • app update lifecycle
  • startup overlay
  • permission/question modal coordinator
  • onboarding/purchase campaign 生命周期

以 feature-specific hooks 承载状态，而不是全部堆在顶层组件。
