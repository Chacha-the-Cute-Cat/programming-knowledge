LobsterAI Final Report

1. 项目整体架构

单包 Electron + React，OpenClaw 作为 Agent Runtime。

2. Electron 架构

Main 编排、Preload 安全桥、Renderer UI，三类进程通过 IPC 协作。

3. IPC

invoke/handle、send/on、webContents.send、流式事件四种模式。

4. WebSocket

OpenClaw Gateway loopback WS、ASR WS、IM 平台、Browser CDP 多类连接。

5. OpenClaw

独立 gateway 进程，负责 Session/Agent/Tool/LLM/MCP；LobsterAI 负责桌面、配置、审批、持久化。

6. LLM

OpenClaw 内 src/llm；LobsterAI 通过 provider config、token proxy、compatibility patch 接入。

7. Agent Runtime

CoworkEngineRouter -> OpenClawRuntimeAdapter -> GatewayClient -> Gateway。

8. Agent Loop

OpenClaw embedded-agent-runner；prompt -> context -> LLM -> tool -> result -> LLM。

9. Context

OpenClaw context-engine，含 history、memory、files、skills、tool result、compaction。

10. Tool

OpenClaw agent-tools、MCP、bash、file、browser、skill。

11. Shell

OpenClaw bash-tools -> exec host -> child_process。

12. Permission

UI/IM -> Approval Bridge -> OpenClaw policy -> tool executor；凭据 sandbox 隔离。

13. Storage

SQLite + OpenClaw state dir。

14. Streaming

Provider -> Gateway -> Adapter -> IPC -> Redux -> React。

15. Performance

主窗口早于 skill bootstrap；OpenClaw 异步启动；main bundle 因 inlineDynamicImports 和未 minify 较大。

16. Security

contextIsolation/sandbox + approval + credential isolation + OpenClaw tool policy。

17. Agent Sensor

见 22-agent-security-sensor.md 与 FINAL-AGENT-SECURITY.md。

18. Agent Identity

现有 agentId/sessionId/runId/messageId/requestId；建议新增统一 agentTraceId 链。

19. Agent Security Graph

见 24-agent-security-graph.md 与 diagrams/15-agent-security-graph.mmd。

20. 最值得学习的源码

  • src/main/libs/openclawEngineManager.ts
  • src/main/libs/agentEngine/openclawRuntimeAdapter.ts
  • src/main/libs/openclawConfigSync.ts
  • src/main/preload.ts
  • OpenClaw src/gateway/client.ts
  • OpenClaw src/gateway/server/ws-connection.ts
  • OpenClaw src/agents/embedded-agent-runner/
  • OpenClaw src/context-engine/

21. LobsterAI 的关键设计模式

  • 桌面壳 + 独立 Agent Runtime 进程 + loopback WebSocket
  • 配置同步与 gateway 热重启
  • 多层审批桥
  • 凭据隔离
  • 异步启动和 startup profiler

22. 可迁移到 Chacha Runtime 的设计

  • Gateway/Client 分离
  • Approval bridge 与 policy 分离
  • Agent trace/identity 关联
  • context compaction 质量保障

23. 可改进的地方

  • main.ts 单文件过大
  • main bundle 过大
  • identity chain 尚未全局统一
  • Sensor 与 OS 监控未内建

24. Mini Agent

见 analysis/mini-agent/，实现了可运行的 mini Agent Loop。

25. 后续学习路线
