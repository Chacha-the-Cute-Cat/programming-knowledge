Phase 14 — Tool Architecture

1. 功能

Tool 是 Agent 与环境交互的能力：Shell、File、Browser、Search、Git、MCP、Custom Tool、Skill。

4. Tool 调用链

LLM tool_call
  -> before-tool-call approval/policy
  -> tool executor
  -> MCP / bash / file / browser / skill
  -> tool result
  -> context update

6. 学习重点

  • Tool 定义和执行主体在 OpenClaw，审批由 OpenClaw 和 LobsterAI 协作完成。
  • MCP 既是 tool source，也有独立的 lifecycle/resolver。
