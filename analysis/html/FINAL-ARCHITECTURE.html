LobsterAI Final Architecture

1. LobsterAI 是什么架构

[源码已确认] 单包 Electron + React 桌面应用，OpenClaw 作为独立 Agent Runtime/Gateway。

React Renderer -> Preload -> Electron Main -> Cowork Router -> OpenClaw Adapter -> OpenClaw Gateway

2. Electron 负责什么

  • 窗口与生命周期
  • 主进程能力：文件、进程、网络、shell、系统通知
  • SQLite 持久化
  • IPC 编排
  • OpenClaw gateway 进程管理
  • IM、MCP、Skill、Cron、Update

3. Renderer 负责什么

  • React UI
  • 会话和消息展示
  • 权限/问题弹窗
  • 配置、artifact、library、scheduled task、IM、MCP、skill 页面

4. Main 负责什么

Main 是最高信任区，负责所有系统级能力和服务编排。

5. Preload 为什么存在

[源码已确认] nodeIntegration:false、contextIsolation:true、sandbox:true，preload 通过 contextBridge 暴露窄 API，保证 Renderer 不能直接访问 Node。

6. IPC 怎么工作

Renderer 调 window.electron.*，preload 调 ipcRenderer.invoke/send，Main 用 ipcMain.handle/on 响应，并用 webContents.send 推送事件。

7. Agent Runtime 在哪里

  • 路由：src/main/libs/agentEngine/coworkEngineRouter.ts
  • 适配：src/main/libs/agentEngine/openclawRuntimeAdapter.ts
  • 底层：OpenClaw embedded-agent-runner

8. Agent Loop 怎么运行

用户 prompt -> Cowork startSession -> Gateway chat.send -> OpenClaw runner -> LLM -> tool call -> tool 执行 -> result -> LLM，直到 final。

9. Context 怎么构建

OpenClaw context-engine 组合 system prompt、history、memory、files、tool result、skills、AGENTS.md，并执行 compaction。

10. LLM 怎么调用

LobsterAI 生成 OpenClaw provider/model 配置；真实调用在 OpenClaw src/llm。LobsterAI 提供 token proxy 和后端代理兼容。

11. Tool 怎么执行

LLM tool_call -> OpenClaw before-tool-call approval/policy -> executor -> tool/MCP/bash/file/browser。

12. Shell 怎么执行

OpenClaw bash-tools -> exec host -> child process -> stdout/stderr/exit code，LobsterAI 侧只保留部分直接 child_process 调用。

13. Process 怎么产生

OpenClaw gateway 由 OpenClawEngineManager spawn；agent tool 进程由 OpenClaw bash/process registry 管理；skill/updater 等由 Main 管理。

14. OpenClaw 在哪里

vendor/openclaw-runtime/current，源码 checkout 在 ../openclaw，版本固定 v2026.8.1。

15. WebSocket 怎么连接

OpenClawEngineManager.getGatewayConnectionInfo() 返回 ws://127.0.0.1:<port>；adapter 创建 GatewayClient(url, token, role=operator, scopes=['operator.admin'])。

16. Permission 怎么控制

UI/IM -> Approval Bridge -> Approval Controller -> OpenClaw policy -> tool executor；凭据走独立 sandbox 页面。

17. 数据怎么持久化

LobsterAI SQLite + OpenClaw state dir；两类数据通过 adapter/config sync/session mapping 对齐。

18. Streaming 怎么传输

Provider -> OpenClaw -> Gateway events -> Adapter -> Main IPC -> Preload -> Redux -> React。

19. 错误怎么处理

Gateway client 重连 + adapter timeout degradation + OpenClaw watchdog/abort + UI error classification。

20. 整个 Agent 执行链

User Intent -> Session -> Turn -> Context -> LLM Decision -> Tool Call -> Approval -> Tool Execution -> Process -> File/Network
