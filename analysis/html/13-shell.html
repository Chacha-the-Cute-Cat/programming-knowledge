4. Shell 执行模型

[推测，待 Phase 5 深挖] OpenClaw bash 工具应负责：

  • command 生成
  • approval request
  • spawn host（node / gateway）
  • stdout/stderr 捕获
  • exit code
  • timeout/cancel/process registry

5. 时序图

sequenceDiagram
  participant LLM as LLM
  participant TOOL as Bash Tool
  participant HOST as Exec Host
  participant OS as Shell/OS
  LLM->>TOOL: tool_call(command)
  TOOL->>TOOL: approval / policy
  TOOL->>HOST: spawn(command, cwd, env)
  HOST->>OS: child process
  OS-->>HOST: stdout/stderr/exitCode
  HOST-->>TOOL: ToolResult
  TOOL-->>LLM: tool result

6. 安全分析

  • shell 是最危险的工具，必须有审批和安全 bin/command 策略。
  • bash-process-registry 说明进程注册与取消是重点。
  • Windows 下 cmd.exe / powershell / Git Bash 的选择会影响路径和命令语义。
